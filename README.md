## 什么是 API 中转站

API 中转站从 Anthropic/OpenAI/Google 等官方渠道批量采购 API 额度，再以更灵活方式分发给国内开发者，支持微信/支付宝支付。

## 收录标准

- 提供标准 OpenAI/Anthropic 兼容 API
- 支持流式输出 (SSE)
- 有明确的定价页面
- 运营时间超过 1 个月

## 如何判断真假

1. **身份测试**：问 "What model are you?" 看回答
2. **知识截止**：问 2025-2026 事件
3. **复杂推理**：球棒+球=$1.10，球多少钱？
4. **流式输出**：是否支持 SSE
5. **价格合理性**：低于官价 3 折基本有假

## 风险提示

- 2026 年 6 月，国家安全部发布 AI 中转市场风险提示
- 部分中转站存在模型假冒、数据泄露、恶意代码注入等问题
- 建议小额充值、用多少充多少
- 敏感数据不要走中转站
